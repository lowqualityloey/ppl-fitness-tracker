#### Traps recorded so they are not rediscovered

1. **Direct database connections are IPv6-only on new Supabase projects.** `db.<ref>.supabase.co:5432` fails `ENETUNREACH` from an IPv4 host. Use the pooler: `postgres.<ref>@aws-0-<region>.pooler.supabase.com:5432` (session) or `:6543` (transaction).
2. **`vercel env add` refuses a `NEXT_PUBLIC_` variable whose value looks like a credential unless a type is chosen.** It returns `action_required / public_prefix_requires_type` and **silently adds nothing** otherwise. The anon key is public by design — RLS is the guard — so `--type config` is correct.
3. **`vercel redeploy` rejects `--yes`** (it accepts `--non-interactive`), and **`</dev/null` overrides a pipe** — which is how an earlier `vercel env add` silently registered nothing.
4. **Free projects pause themselves after a week of inactivity**, so `shelf` may have been heading for a pause anyway.
